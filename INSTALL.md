### [Veilamp](https://veilamp.com)

#### Install using Git

If you are a Git user, you can install the theme and keep it up to date by cloning the repo:

```bash
git clone https://github.com/dracula/veilamp.git
```

#### Install manually

Download using the [GitHub `.zip` download](https://github.com/dracula/veilamp/archive/main.zip) option and unzip it.

#### Activating theme

**As a single file**

1. Open the **Skins** tab in Veilamp.
2. Choose **Import theme…**.
3. Select `skin.json`.

**As a skin package**

1. Navigate to **Settings > Appearance > Skin packages**.
2. Choose **Import folder…** (or **Import .zip…**).
3. Select this repository's folder or a zip of it.
