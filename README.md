# Dracula for [veilamp](https://gitlab.com/wrewtopia-labs-group/Veilamp)

> A dark theme for [veilamp](https://gitlab.com/wrewtopia-labs-group/Veilamp).

## Install

All instructions can be found at [draculatheme.com](https://draculatheme.com).

### Single file

1. Download `skin.json` from this repo.
2. In veilamp open the **Skins** tab and choose **＋ Import theme…**.
3. Pick `skin.json`. "Dracula" now appears in the palette picker.

### As a skin package

1. Clone or download this repo as a folder (or `.zip`).
2. In veilamp open **Settings → Appearance → Skin packages → ＋ Import folder…**
   (or **＋ Import .zip…**).
3. Pick the folder or archive.

## Variants

The theme ships four accent variants, selectable from the chips on the theme's
card in the palette. The choice is remembered.

| Variant | Primary accent | Secondary accent |
| --- | --- | --- |
| Purple (default) | `#bd93f9` Purple | `#ff79c6` Pink |
| Cyan | `#8be9fd` Cyan | `#bd93f9` Purple |
| Pink | `#ff79c6` Pink | `#bd93f9` Purple |
| Green | `#50fa7b` Green | `#8be9fd` Cyan |

VU meters and warm highlights use Dracula Orange `#ffb86c` and Yellow `#f1fa8c`
in every variant.
